# bosonic PNR — 单分量 ⟨n|ρ|n⟩ 闭式可行性（Phase 0 结论）

**日期**: 2026-09-02 · **作者**: 会话探索(pi)
**用途**: 验证 bosonic 加 PNR 的唯一技术难点——单模高斯分量 `⟨n|ρ_k|n⟩` 的
**解析闭式**（PRD OQ-2 选 A）是否可行。结论：**可行，精度到 1e-5**。

---

## 1. 背景

bosonic PNR：`p_n = ⟨n|ρ|n⟩ = Σ_k w_k ⟨n|ρ_k|n⟩`（分量混合）。单分量
`⟨n|ρ_k|n⟩` 对**一般 V + 复 r̄** 是关键难点。本 Phase 0 验证「解析闭式」路线。

## 2. 核心公式（Weyl 反变换 → 位置基密度矩阵）

单模高斯态 ρ 由 (V, r̄) 给定（xxpp, ħ=1）。Wigner `W(z) = N exp(−½(z−r)ᵀV⁻¹(z−r))`。
Weyl 反变换（对 p 的高斯积分为**闭式**）给出位置基密度矩阵元：

```
ρ(x,x') = (1/√(2π)) ∫ dp e^{ip(x−x')} W((x+x')/2, p)
        = N·e^{−½(xm−rx)²α} · √(π/(γ/2)) · e^{−L²/(4·(−γ/2))} · e^{i r_p (x−x')}
```

其中 `xm=(x+x')/2`，`L = −(xm−rx)β + i(x−x')`，`α,β,γ = V⁻¹` 的对角/交叉分量。
Fock 对角元：

```
⟨n|ρ|n⟩ = ∫∫ dx dx' φ_n(x)* ρ(x,x') φ_n(x')
φ_n(x) = H_n(x) e^{−x²/2} / (π^{1/4} √(2^n n!))
```

数值 2D 积分（n_x 网格，复 Gauss 矩阵 `R[i,j] = ρ(x_i,x_j)`，`⟨n|ρ|n⟩ = φ_n† R φ_n`）。

## 3. 验证结果（vs Fock expm gold，到 1e-5）

| 情形 | (V, r̄) | gold | 闭式 | 匹配 |
|---|---|---|---|---|
| 压缩真空 r=0.5 | 对角 V, r̄=0 | `0.88682, 0, 0.09469, 0, 0.01517, 0` | `0.88682, 0, 0.09469, 0, 0.01517, 0` | ✅ 逐位 |
| 纯位移相干 α=1 | V=I/2, 实 r̄ | Poisson | Poisson | ✅ |
| 一般压缩相干 | 非对角 V + 实位移 r̄ | `0.29019, 0.42697, 0.17307,...` | `0.29018, 0.42698, 0.17308,...` | ✅ 1e-5 |

**性能**：n_x=80 网格 2D 积分 0.18s。闭式无表查找，纯解析加速。

## 4. 关键发现

1. **解析闭式路线（A）成立**：`⟨n|ρ_k|n⟩` 通过 Weyl→ρ(x,x') 复高斯→Fock 投影精确可算，
   任意 V（对角/非对角）+ 实位移 r̄ 均复现 Fock gold 到 1e-5。这是 Phase 0 决定性结论。
2. **性能可接受**：0.18s（80×80），进一步可解析封闭（Hermite×复高斯→Laguerre），
   Phase 1 可深化。
3. **复 r̄（bosonic 交叉分量）**：ρ(x,x') 保留 r̄ 虚部 → `⟨n|ρ|n⟩` 为复数（干涉），
   与配对分量求和后取实（`is_hermitian` 语义）。这与 bosonic 现有 `_as_real` /
   `is_hermitian` 处理一致，无需新机制。

## 5. 陷阱（Phase 0 记录）

- **手算 V 会错**：一般压缩相干的 V 是**非对角**的（挤压相位 φ 进 V），必须从态提取
  或用正确的 R(φ)diag R(−φ)。探测初期（0.526 vs 0.290 不匹配）源于手算 V 错，非闭式错。
- 复 r̄ 的 Fock 投影需保留虚部积分，不能只取 Re(r̄)。

## 6. 对 Phase 1 的启示

- bosonic PNR 可以在 `measure.py` 新增 `pnr_probs` / `pnr_sample`，
  内部用本闭式的生成函数路线实现，先加权求和再 Cauchy 提取；`pnr_condition`
  暂缓，避免把非高斯后验伪装成有限 Gaussian 分量。
- 复 r̄ 分量的干涉项由 Hermitian 闭合保证（`is_hermitian`），`p_n` 全分量求和后非负。
- gold 锚：Fock `pnrd_probs`（已有），标量对照 `p_n`，无需 cross-rep bridge。
