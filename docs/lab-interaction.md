## 1. 页面分区

```
┌─────────┬──────────────────────┬──────────────┐
│  托盘    │  五线谱（电路画布）      │  右栏仪表      │
│ palette │  ┌────┬────────────┐ │  Wigner 热图   │
│  ops    │  │源区 │ 格子轨道区   │ │  分析量/仪表    │
│         │  └────┴────────────┘ │  扫描面板      │
├─────────┼──────────────────────┴──────────────┤
│ 状态栏 status + 运行按钮                        │
└─────────┴─────────────────────────────────────┘
```

| 区域 | 职责 |
|------|------|
| **托盘** | 可添加的量子操作卡片（白名单制）。点击 = 添加，拖拽 = 指定位置放置 |
| **五线谱** | 核心画布。左端**源区**（光源/真空态），右侧**格子轨道**（放置门） |
| **状态栏** | 单行反馈：`ok`（深色）提示成功/信息，`error`（红色）提示拒绝原因 |
| **右栏** | 选定单模 Wigner 热图（防抖刷新）、分析量仪表、`E_N(r)` 扫参面板 |

## 2. 格子模型（L5.5 核心）

五线谱的放置区是**预定义格子**，不是自由坐标：

- **列**：x 为**非负整数**，每列宽 `GATE_W = 72px`。列无限延伸，超出可视宽度时画布**横向滚动**。
- **行（轨道）**：每个光学模式一条轨道，行高 `ROW_H = 56px`。
- **源区**：画布最左 `SRC_W = 132px`，放置源（真空模/压缩源），不属于格子。
- **单元格** = (mode, x)。门占一个或多个格。
- **吸附规则**：任何拖放位置都 `round` 到最近整数列（`x = max(0, round((clientX - 画布左缘 - SRC_W) / 72))`）。拖放、拖动已有门、JSON 载入三处一致。
- **冲突**：同一轨道同一列已有门（或双模门的任一端所在格）即冲突。**冲突 = 拒绝**，放下时被驳回并提示。
- **画布宽度**：`132 + max(10, 最右门列 + 4) × 72` px——初始至少 10 个空列，门放满后最右仍留 4 列余量，保证随时有空格可拖放。
- **格子线**：每 72px 一条淡色垂直线（对齐列边界），门块（60×44px）位于格内。

## 3. 添加器件

### 3.1 点击托盘（快捷方式）

| 类型 | 行为 |
|------|------|
| 单模门（相位/位移/压缩/损耗等） | 加到 **mode 0**，x = 当前最右列 + 1（依次向右排） |
| 双模门（分束器/MZ/双模压缩） | 加到 **modes [0, 1]**，x = 最右列 + 1；若模式数 < 2 拒绝并提示 |
| 源（真空模/压缩源） | 直接追加为新源（见 §8） |

### 3.2 拖拽托盘卡片 → 五线谱（主要方式）

1. **按住卡片拖起**（`dragstart`）：载荷记入内部状态（浏览器在 dragover 期间读不到 `dataTransfer`，实现用闭包）。
2. **悬停格子**（`dragover`）：实时计算落点列，反馈三选一：
   - **空格**：该格背景高亮 + 出现**虚线预览块**（`相位 ?` 样式，居中于格）；
   - **被占格**：该格背景**变红** + 预览块变红——放下前就能看出会冲突；
   - **无效目标**（源区/源卡片/非门操作）：无预览。
3. **放下**（`drop`）：
   - 空格 → 放置成功，门落在格内；
   - 被占格 → **拒绝**，状态栏提示 `该格已被占用（mode X @ x Y）`，画布不变；
   - 拖到轨道以外 → 放弃，无效果。
4. **拖走**（`dragend`）：清理预览。

> 源类卡片**不参与拖放**（拖到轨道上会提示"源：请用托盘点击添加"）；`coherent` 源已移出托盘（旧 JSON 仍可载入，见 §8）。

## 4. 双模门的两步放置

分束器 / MZ / 双模压缩占**两个格**（两个轨道同一列），落定后两格都锁定：

1. **第一步**：拖卡片到某个轨道（mode A）某列 → 出现半透明预览块 `分束器 ?`，该轨道被"武装"（源区对应行也高亮）。
2. **第二步**：点击另一条轨道（mode B）：
   - mode B 与 mode A **不同** 且 B 格空闲 → 落定，门横跨两轨，两个格都被占；
   - mode B **等于** mode A → 拒绝 `双模操作需要两个不同模式`；
   - mode B 格**被占** → 拒绝 `该格已被占用（mode B @ x Y）`，**保持第一步状态**，可改选其他轨道；
   - 点击轨道以外（空白处）→ 取消放置。
3. 放置状态由状态栏提示引导：`选择第二个模式（当前 mode A）`。

---

## 5. 移动已有门

拖动任何已放置的门（单模或双模）：

- **预览**：悬停时显示 `↔` 预览块（占两轨的门预览跟随），目标格高亮/红显；
- **落点**：round 到最近整数列；目标格（双模查两格）被占 → 拒绝 `该格已被占用（x Y）`，门留在原位；
- **成功**：门移到新列，JSON 同步更新，节点排序随 (x, mode) 重排。
- 源块**不可拖**（源在源区固定）。

## 6. 删除与参数编辑

| 操作 | 方式 | 说明 |
|------|------|------|
| **删除门** | 悬停门块 → 右上角出现 `×` → 点击 | 立即移除，JSON 同步 |
| **编辑参数** | 点击门块（或点击源块） | 弹出参数卡片（定位在门附近） |
| **拧参数** | 卡片内滑块（`input[type=range]`） | 实时写回 state + JSON + 电路图（右栏防抖刷新） |
| **源参数** | 点击源块 → 卡片 | 如 `tmsv(r)`、`coherent(α)` 只读展示 |
| **高级参数** | — | `nbar`/`nmode` 等标 `advanced` 的参数**只在 JSON 里改**，卡片不显示 |

参数卡片点击门块外部自动关闭；卡片本身点击不穿透。

## 7. 源：多源模型（L5.5 后端扩展）

- **默认场景**：两个真空模（mode 0/1）各接一个位移器（α = 1，x = 0），运行得两路相干态。
- **多源合法**：`circuit_v0` 允许**多个源节点连续排列**（所有源必须在第一个门之前），后续源 = 直积追加独立模式。例：`vacuum(nmode=1)` + `tmsv(r)` = 3 模式。
- **非法**：门之后再出现源 → 后端 422，前端冻结图形并提示（见 §10）。
- **删除源**：无 UI 按钮，通过 JSON 文本编辑（删节点行）。删除后若仍有门引用被删的模式 → 后端 422 + 图形冻结，需一并删除相关门。

---

## 8. JSON 文本编辑（高级/兜底）

- 底部 JSON 文本域是**同步视图**：任何画布操作即时回写；反向编辑文本 → 400ms 防抖后重绘画布。
- **冻结策略（frozen-graph）**：文本非法（语法错/模式越界/门后插源/schema 不符）→ 画布**冻结**为最近一次合法图，状态栏报错 `JSON 语法错误：图形已冻结`（红色）。改回合法文本自动解冻重绘。
- **legacy 兼容**：无 `ui.x` 的老 JSON 载入时按出现顺序补列（0, 1, 2…）。
- **reset 按钮**：恢复默认场景。

---

## 9. 运行与反馈

- 画布/参数每次变化 → 防抖 120ms 自动 `/run`（无手动运行按钮的心智模型；显式按钮仅用于手动重跑/扫参场景）。
- 状态栏显示结果：`ok · 384 ms · …`（含光子数、纯度等）或错误原因。
- 后端校验失败（422）→ 状态栏红色提示 + 图形冻结。

---

## 10. 扫描面板（L4）

1. **节点选择**：只列**有可扫参数**的节点（如 `tmsv(r)`、`loss(T)`）；`scan` 参数白名单在 `OPS[n].params[k].sweep` 定义。
2. **参数选择**：自动跳到该节点第一个可扫参数；min/max/点数按参数元数据自适应默认。
3. **modes_A**：选择用于计算 `E_N` 等双模量的 A 侧模式（默认 `[0]`）。
4. **运行**：模式数 < 2 时按钮禁用；完成后状态栏 `scan ok · N 点 · T ms`，面板内画 SVG 曲线（如 `E_N(r) ≈ 2r/ln2` 对照解析式）。

## 11. 交互规则速查表

| 场景 | 反馈 | 结果 |
|------|------|------|
| 拖到空格 | 格高亮 + 虚线预览 | 放下成功 |
| 拖到被占格 | 格变红 + 预览变红 | 放下拒绝，提示占用格 |
| 拖源卡片 | 无预览 | 提示"源：请用托盘点击添加" |
| 双模第一步 | 半透明预览 + 轨道武装 | 等第二步 |
| 双模第二步同轨 | 状态栏 | 拒绝"需要两个不同模式"，保持第一步 |
| 双模第二步被占格 | 状态栏 | 拒绝，保持第一步 |
| 移动门到被占格 | 格变红 | 拒绝，门留原位 |
| JSON 非法 | 状态栏红字 | 图形冻结 |
| 点击源块 | 参数卡片 | 只读展示 |
