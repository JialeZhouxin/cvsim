## 2. 格子模型（L5.5 核心）

五线谱的放置区是**预定义格子**，不是自由坐标：

- **列**：x 为**非负整数**，每列宽 `GATE_W = 72px`。列无限延伸，超出可视宽度时画布**横向滚动**。
- **行（轨道）**：每个光学模式一条轨道，行高 `ROW_H = 44px`。行数 = `state.nmode`。
- **模行标签区**：画布最左 `MODE_W = 132px`，每模一行，显示 `mode N · <初始态>` 与删模 `×` 按钮，不属于格子。
- **单元格** = (mode, x)。门占一个或多个格。
- **吸附规则**：任何拖放位置都 `round` 到最近整数列（`x = max(0, round((clientX - 画布左缘 - MODE_W) / 72))`）。拖放、拖动已有门、JSON 载入三处一致。
- **冲突**：同一轨道同一列已有门（或双模门的任一端所在格）即冲突。**冲突 = 拒绝**，放下时被驳回并提示。
- **画布宽度**：`132 + max(10, 最右门列 + 4) × 72` px——初始至少 10 个空列，门放满后最右仍留 4 列余量，保证随时有空格可拖放。
- **格子线**：每 72px 一条淡色垂直线（对齐列边界），门块（60×44px）位于格内。

## 3. 添加器件

### 3.1 点击托盘（快捷方式）

| 类型 | 行为 |
|------|------|
| 单模门（相位/位移/压缩/损耗等） | 加到 **mode 0**，x = 当前最右列 + 1（依次向右排） |
| 双模门（分束器/MZ/双模压缩） | 加到 **modes [0, 1]**，x = 最右列 + 1；若 `state.nmode < 2` 拒绝并提示 |

### 3.2 拖拽托盘卡片 → 五线谱（主要方式）

1. **按住卡片拖起**（`dragstart`）：载荷记入内部状态（浏览器在 dragover 期间读不到 `dataTransfer`，实现用闭包）。
2. **悬停格子**（`dragover`）：实时计算落点列，反馈三选一：
   - **空格**：该格背景高亮 + 出现**虚线预览块**（`相位 ?` 样式，居中于格）；
   - **被占格**：该格背景**变红** + 预览块变红——放下前就能看出会冲突；
   - **无效目标**（模行标签区/非门操作）：无预览。
3. **放下**（`drop`）：
   - 空格 → 放置成功，门落在格内；
   - 被占格 → **拒绝**，状态栏提示 `该格已被占用（mode X @ x Y）`，画布不变；
   - 拖到轨道以外 → 放弃，无效果。
4. **拖走**（`dragend`）：清理预览。

> 托盘只有门/通道/测量三组（ADR-0014 退役「源」组）；加模用工具栏「＋模」按钮或模行右侧的删模 `×`（见 §7）。

## 4. 双模门的两步放置

分束器 / MZ / 双模压缩占**两个格**（两个轨道同一列），落定后两格都锁定：

1. **第一步**：拖卡片到某个轨道（mode A）某列 → 出现半透明预览块 `分束器 ?`，该轨道被"武装"（模行标签也高亮）。
2. **第二步**：点击另一条轨道（mode B）：
   - mode B 与 mode A **不同** 且 B 格空闲 → 落定，门横跨两轨，两个格都被占；
   - mode B **等于** mode A → 拒绝 `双模操作需要两个不同模式`；
   - mode B 格**被占** → 拒绝 `该格已被占用（mode B @ x Y）`，**保持第一步状态**，可改选其他轨道；
   - 点击轨道以外（空白处）→ 取消放置。
3. 放置状态由状态栏提示引导：`选择第二个模式（当前 mode A）`。

---

## 5. 移动已有门

拖动任何已放置的门（单模或双模）：

- **预览**：悬停时显示 `↔` 预览块（占两轨的门预览跟随），目标格高亮/红显；
- **落点**：round 到最近整数列；目标格（双模查两格）被占 → 拒绝 `该格已被占用（x Y）`，门留在原位；
- **成功**：门移到新列，JSON 同步更新，节点排序随 (x, mode) 重排。
- 模行标签区**不是拖放目标**（不可拖、不可放）。

## 6. 删除与参数编辑

| 操作 | 方式 | 说明 |
|------|------|------|
| **删除门** | 悬停门块 → 右上角出现 `×` → 点击 | 立即移除，JSON 同步 |
| **删除模** | 模行右侧 `×` → 点击 | 删除该模及其上的全部门，上方模索引整体 −1；`nmode === 1` 时按钮禁用 |
| **编辑参数** | 点击门块 | 弹出参数卡片（定位在门附近） |
| **拧参数** | 卡片内滑块（`input[type=range]`） | 实时写回 state + JSON + 电路图（右栏防抖刷新） |
| **模标签** | 不可点击（纯标签） | 初始态只在右侧「初始态」卡编辑（ADR-0014 D2(i)） |
| **高级参数** | — | `nbar` 等标 `advanced` 的参数**只在 JSON 里改**，卡片不显示 |

参数卡片点击门块外部自动关闭；卡片本身点击不穿透。

## 7. 模行：模数模型（ADR-0014）

- **默认场景**：2 个模（`nmode = 2`），各接一个位移器（α = 1，x = 0），运行得两路相干态。
- **模数唯一事实源 = `state.nmode`**：左列每模一行，行数恒等于 `state.nmode`；IR 顶层 `nmode` 即由此写出。
- **无源节点**：前端 `state.nodes` 只含门/通道/测量；模的「初始态」是 `state.initial` 数组（per-mode），不是节点。
- **标签诚实**：标签 = `mode N · <初始态>`，直接读 `state.initial[N]`——fock 下 3 光子写 `mode 0 · |3⟩`，bosonic 下写源名，gaussian 恒「真空」（gaussian 无 `initial` 字段，定义如此）。
- **加模**：工具栏「＋模」按钮（恒可见）。
- **删模**：模行右侧 `×` → 删除该模**及其上的全部门**（双模门只要一端命中即删），索引 `> mode` 的模整体 −1；`state.initial`/`state.cutoffs` 按索引删除（非截尾）。`nmode === 1` 时按钮禁用。
- **越界夹紧**：删模后 `view.wigner_mode` 夹到 `nmode − 1`；`view.joint_modes` 任一索引越界 → 清空（回退默认 `[0,1]`）。
- **含源 op 的旧 JSON 被拒**：`"op": "vacuum"` / `"tmsv"` / `"coherent"` 不在白名单内，导入即报错（故意行为，见 ADR-0014）。

## 8. JSON 文本编辑（高级/兜底）

- 底部 JSON 文本域是**同步视图**：任何画布操作即时回写；反向编辑文本 → 400ms 防抖后重绘画布。
- **冻结策略（frozen-graph）**：文本非法（语法错/模式越界/schema 不符/含已退役源 op）→ 画布**冻结**为最近一次合法图，状态栏报错 `JSON 语法错误：图形已冻结`（红色）。改回合法文本自动解冻重绘。
- **legacy 兼容**：无 `ui.x` 的老 JSON 载入时按出现顺序补列（0, 1, 2…）。
- **reset 按钮**：恢复默认场景。

---

## 9. 运行与反馈

- 画布/参数每次变化 → 防抖 120ms 自动 `/run`（无手动运行按钮的心智模型；显式按钮仅用于手动重跑/扫参场景）。
- 状态栏显示结果：`ok · 384 ms · …`（含光子数、纯度等）或错误原因。
- 后端校验失败（422）→ 状态栏红色提示 + 图形冻结。

## 10. 扫描面板（L4）

1. **节点选择**：只列**有可扫参数**的节点（如 `tmsv(r)`、`loss(T)`）；`scan` 参数白名单在 `OPS[n].params[k].sweep` 定义。
2. **参数选择**：自动跳到该节点第一个可扫参数；min/max/点数按参数元数据自适应默认。
3. **modes_A**：选择用于计算 `E_N` 等双模量的 A 侧模式（默认 `[0]`）。
4. **运行**：模式数 < 2 时按钮禁用；完成后状态栏 `scan ok · N 点 · T ms`，面板内画 SVG 曲线（如 `E_N(r) ≈ 2r/ln2` 对照解析式）。

## 11. 交互规则速查表

| 场景 | 反馈 | 结果 |
|------|------|------|
| 拖到空格 | 格高亮 + 虚线预览 | 放下成功 |
| 拖到被占格 | 格变红 + 预览变红 | 放下拒绝，提示占用格 |
| 双模第一步 | 半透明预览 + 轨道武装 | 等第二步 |
| 双模第二步同轨 | 状态栏 | 拒绝"需要两个不同模式"，保持第一步 |
| 双模第二步被占格 | 状态栏 | 拒绝，保持第一步 |
| 移动门到被占格 | 格变红 | 拒绝，门留原位 |
| JSON 非法 | 状态栏红字 | 图形冻结 |
| 点击模标签 | 无反应 | 纯标签（D2(i)） |
| 点击模行 `×`（nmode=1） | 无反应 | 按钮 disabled |
