# PRD — L5.5 staff 格子化与默认场景重构

## 背景

L5 五线谱电路编辑器（cvsim/lab/static）当前拖放位置是鼠标换算的任意实数 x，托盘点击追加自动放 maxX+1（"自动计算位置"）。用户要求：五线谱预定义格子，器件只能放格子里，交互清晰、可预览。

## 已锁定决策（2026-08-05 grilling 会话，6 项共识）

1. **格子 = 离散 x 整数列**（0,1,2,…），无限延伸 + 横向滚动；轨道（行）= mode 不变。
2. **冲突 = 拒绝**：同轨道同列已有门 → 拒绝 + 状态栏提示；拖拽悬停时就高亮红显预告，不等放下才报错。
3. **coherent 源移出 UI 托盘**：`palette: false`（与 tmsv 同模式，保留 OPS 定义 → 旧 JSON 仍可载入）；后端 IR 不动。
4. **默认场景**：两个独立 vacuum（mode 0/1，各 1 模）+ 两个 displace 门 @ x=0、alpha=1.0。替换现 tmsv + loss×2 场景。
5. **双模门占两格**：落定后 (modeA,x) 与 (modeB,x) 都锁死；两步放置第二步选 B 轨道时若该格被占则拒绝。
6. **snap = round**：拖放与拖动已有门（moveNodeX）都四舍五入到最近整数列；悬停高亮目标格 + 幽灵块预览，所见即所得。

## 验收标准

- [ ] 默认场景渲染：2 条轨道（2 个独立真空源）+ 2 个 displace 门 @ x=0，点击运行出 coherent 态结果
- [ ] 拖放单模门 snap 到整数列（round），悬停显示目标格高亮；目标格被占 → 红显 + 放下拒绝 + 状态栏提示
- [ ] 拖动已有门同样 round + 冲突拒绝（目标格非自身原格）
- [ ] 双模门两步放置：第一步锁定列，第二步选 B 轨道；B 格被占 → 拒绝 + 提示；落定后两格锁死
- [ ] coherent 不在托盘出现；含 coherent 的旧 JSON 仍可载入且渲染正常
- [ ] 格子视觉：淡色垂直虚线分列，器件对齐格子
