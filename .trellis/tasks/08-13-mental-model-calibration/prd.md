# PRD · 心智模型校准文档

## Goal

产出用户心智模型校准文档（markdown，仓库根），使 AI 未来会话能以用户认知框架（而非 AI 默认框架）解释、教学、决策。认知科学视角：心智模型校准（mental model calibration）——AI 的"用户模型"对齐用户实际认知模型。

## Requirements

1. 独立 markdown 文档落仓库根，中文
2. 内容结构：领域认知（Q2–Q5）/ 方法论（Q6–Q8）/ 协作协议（Q9–Q10、Q12）/ 使用说明（AI 如何用）
3. AGENTS.md 挂指针（TRELLIS 块外追加）
4. 含"反模式清单"——AI 表达禁用项 + 替代动作

## Acceptance Criteria

- [ ] 文档在仓库根，覆盖 Q1–Q12 全部锁定项，无遗漏、无添加未授权内容
- [ ] 反模式清单可执行（每项：禁用表述 → 替代动作）
- [ ] 结构映射规则（Q12）作为顶层解释协议写入
- [ ] AGENTS.md 指针可被发现（任何会话入口读 AGENTS.md 即见）
- [ ] 用户审阅确认

## Out of Scope

- CONTEXT.md 术语不动（只加指针，不合并内容）
- 不写 tutorial、不改 cvsim 代码
- 不生成 ADR
