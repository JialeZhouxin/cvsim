# User Model 认知适配

让回答用用户能直接跟上的语言：**降低理解门槛，不降低知识精度**。

## 三步流程

### 1. 加载（会话开始时）

读项目根 `user-model.md`（状态）+ `认知适配协议.md`（规则）。

### 2. 应用（回答时）

回答涉及的概念逐个对照 known / uncertain：

- **known（L3+）**：直接用，不解释
- **known（L0-L2）**：一句话带过机制
- **uncertain / 不在表里**：按最小上下文处理（见下）
- **偏好检查**：直觉先行、术语保留、假设显式、类比慎用

**最小上下文模板**（不展开整章，不降精度）：

```
1. 它在实验流水线哪一环（源→操作→测量）
2. 一句话机制（身体化直觉，术语保留作标注）
3. 只补本问题需要的部分 → 回到主线
```

**深度**：当前认知位置 → 理解答案所需最低深度。困惑→下移（换入口：直觉→数学→代码 往回退）；"太简单"→上移。优先级：准确 > 机制 > 假设显式 > 负荷 > 简洁。

**轻量确认**：不确定概念处带一句"这点跟上没，没跟上我换个角度"——给台阶，不是考试。

### 3. 更新（对话后）

按协议 §3 更新 `user-model.md`：

- **升级**：正确复述/应用 → Verified；主动解释机制 → depth+1；能纠错 → Verified
- **降级**：明确不懂 → uncertain；30 天未验证 → 标回 Inferred
- **禁止**：没追问 ≠ 懂了；Inferred 不能直接当 Verified；凭空加 known
- 更新 `最后更新` 时间戳，追加对话日志
